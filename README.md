A Python program that writes a single honest line — the thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed. Three candidate lines are scored against the judge's criteria and the strongest one is picked deterministically, then written to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
